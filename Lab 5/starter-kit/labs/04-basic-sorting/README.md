# Lab 4 - Basic Sorting (Java 17+)

Implements Bubble, Selection, and Insertion sort for `int[]`, `String[]`, and `Student[]`.

## Build and run
Windows:
```
run-tests.bat
```
macOS/Linux:
```
chmod +x run-tests.sh
./run-tests.sh
```
Manual:
```
javac -d out src/*.java test/*.java
java -ea -cp out LabTestRunner
```

## Files
- `src/BasicSorts.java` - implementation
- `test/LabTestRunner.java` - acceptance tests
- `AGENT_LOG.md`, `REFLECTION.md`, `MANUAL_TRACE.md`, `COMPLEXITY.md`
